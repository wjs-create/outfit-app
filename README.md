# 今日穿搭原型

这是按照 `产品蓝图.md` 落地的第一版网站。首屏是可试用的穿搭工具，后面包含服务套餐、上线顺序和内测报名。

## 怎么打开

直接打开 `index.html` 即可使用。

也可以在本目录启动一个静态服务后访问：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173`。

## 已实现

- 上传衣服照片并保存到本地浏览器。
- 粘贴商品图链接，用于录入网购衣服。
- 一键导入 5 件网售样衣，用于自己跑通测试流程。
- 记录名称、品类、颜色、材质、厚薄、季节、风格标签、适合场合、网购链接和备注。
- 按关键词和品类筛选数字衣橱。
- 输入温度、天气、心情、场合、想要风格和指定单品。
- 自动生成 1-3 套穿搭建议。
- 用衣物拼贴方式生成预览。
- 记录喜欢 / 不喜欢反馈。
- 在偏好页统计衣橱数量、收藏搭配、常见颜色和常用风格。
- 展示服务套餐和商业化上线顺序。
- 保存内测报名信息到当前浏览器本地。

## 当前边界

- 数据保存在当前浏览器的本地存储里，换浏览器或清理缓存会丢失。
- 天气需要手动输入，还没有接入天气 API。
- 网购链接只保存地址；商品图链接可以手动粘贴，但还没有自动解析商品信息。
- 穿搭生成是本地规则算法，还没有接入 AI。
- 预览图是衣物拼贴，不是真人试穿。

## 自测

运行：

```bash
node test-flow.cjs
```

当前自测会验证：网售样衣能加载、每件样衣都有商品链接、搭配能生成、第一套搭配包含上衣/下装/鞋，并且推荐理由能反映天气和场合。
